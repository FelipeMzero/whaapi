Instalação

Suba em minutos com Docker ou Node.js (NVM).

git clone https://github.com/FelipeMzero/whaapi.git
cd whaapi
cp .env.example .env   # configure sua API_KEY
docker compose up -d --build

# Com RabbitMQ + MinIO opcionais:
docker compose --profile rabbitmq --profile minio up -d
nvm install 20 && nvm use 20
git clone https://github.com/FelipeMzero/whaapi.git
cd whaapi
cp .env.example .env
npm install
npm start

Eventos em tempo real

Cada evento é entregue simultaneamente via Webhook, Socket.io, RabbitMQ, Kafka e SQS. 

import { io } from "socket.io-client";

const socket = io("http://localhost:8080", { query: { instance: "minha" } });

socket.on("messages.upsert", (payload) => {
  console.log(payload.data.number, payload.data.text);
});
